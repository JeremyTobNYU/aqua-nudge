# 2026-09-30, planning

**Goal:** firm up the project direction after the spring proposal.

**Decided:**
- The target setting moves from campus fountains to NYC corporate offices (discussed with Aqvita's CEO).
- The product is a retrofit for the Hydr8 4i bottleless cooler, which is common in NYC offices.
- The feedback expresses a shared, anonymous "mineral level" for the floor, with magnesium as the symbol of healthy living, while nudging people to drink. It is not a nutrition claim.
- Concept A, "Crown & Rails" (cap module, LED rails, nook halo), is preferred over Concept B, "Side Totem".
- A pour is sensed by an inline flow meter (mL) plus a piezo contact mic (valve events). A ToF sensor handles approach detection.
- Work is tracked with GitHub Issues and a board, organized into eight workstreams.

**Problems / next:** get access to a real Hydr8 4i and a test site; order parts; start the DSP engine on a laptop; update the proposal (dates, office setting).
