# Engineering logbook

One file per work session, named `YYYY-MM-DD.md`. Keep each entry short:

```
# YYYY-MM-DD, <workstream>
**Goal:** what this session set out to do (link the issue)
**Did:** what happened, including numbers and measurements
**Decided:** any design decision and why
**Problems / next:** what's blocking and what comes next
```

These entries are the raw material for the ABET midterm and final reports: design decisions, alternatives considered, tests and results.
